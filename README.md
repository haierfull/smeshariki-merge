# Смешарики: Слияние — версия для планшета (Android)

Сенсорная версия игры с теми же персонажами, картинками, музыкой и
механиками (цепочка, «Перемешать», регуляторы громкости), что и в
компьютерной версии. Управление: палец тянется влево/вправо по стакану,
чтобы прицелиться, и отпускается — фишка падает. Макет сам подстраивается
и под портретную, и под альбомную ориентацию планшета.

Все картинки, музыка и звуки, которые ты прислал, уже вставлены — игра
полностью готова к установке, ничего докладывать не нужно.

---

## Как получить .apk файл и поставить его на планшет Вари

Я не могу собрать .apk прямо здесь — для этого нужен Android SDK
(инструменты от Google), а в этой изолированной среде доступ к серверам
Google заблокирован политикой безопасности, скачать их отсюда нельзя.

Но в проект уже встроена автоматическая сборка через **GitHub Actions** —
бесплатный сервис GitHub сам соберёт .apk за 2-3 минуты на своих
серверах, без Android Studio и без единой команды в терминале. Нужно
только один раз загрузить папку на GitHub.

### Шаг 1. Один раз: создать репозиторий и загрузить проект

1. Зайди на **github.com**, войди (или зарегистрируйся — бесплатно,
   минута).
2. Нажми **New repository**. Назови как угодно, например
   `smeshariki-merge`. Публичный (Public) или приватный (Private) —
   не важно.
3. Нажми **Create repository**.
4. На странице репозитория нажми **uploading an existing file** (или
   "Add file" → "Upload files").
5. Перетащи в окно браузера **всё содержимое** этой папки (index.html,
   game.js, config.js, папки assets/, icons/, android/, .github/ — всё
   целиком, с сохранением структуры папок — современный загрузчик
   GitHub умеет принимать перетащенную папку).
6. Нажми **Commit changes**.

### Шаг 2. Дождаться сборки

1. Открой вкладку **Actions** в репозитории — там уже идёт (или вот-вот
   начнётся) сборка **Build APK**.
2. Подожди 2-3 минуты, пока не появится зелёная галочка.

### Шаг 3. Скачать .apk и отправить Варе

Самый простой способ — вкладка **Releases** (справа на главной странице
репозитория): там после сборки появится файл `smeshariki.apk` — обычная
прямая ссылка, скачать может кто угодно, даже без аккаунта на GitHub.
Отправь эту ссылку Варе (в сообщении, почте, куда угодно) — или скачай
сама и перешли файл ей напрямую (например, через Telegram).

На планшете Варя:
1. Открывает .apk файл (через ссылку, или через присланный файл).
2. Android один раз спросит разрешение на установку приложений не из
   Play Store («Установить из неизвестного источника») — это
   стандартное предупреждение для любого APK не из магазина, нужно
   просто один раз его подтвердить.
3. Нажимает «Установить».

Дальше — обычное приложение на рабочем столе, со своей иконкой,
открывается на весь экран, работает полностью офлайн (всё уже внутри
файла, интернет для игры не нужен).

Если захочешь что-то поменять (например, баланс сложности или тексты)
и пересобрать — просто загрузи обновлённые файлы в тот же репозиторий,
Actions пересоберёт apk автоматически, появится новый файл во вкладке
Releases.

## Если не хочется связываться с .apk — альтернатива на один тап

В проекте также осталась возможность запустить игру как обычный сайт
(в `index.html`, `manifest.webmanifest`, `sw.js`) — если выложить эти
файлы на любой бесплатный хостинг с https (например, через **GitHub
Pages** — Settings → Pages в том же репозитории), Варя сможет открыть
ссылку в Chrome и нажать «Добавить на главный экран»: получится
значок на рабочем столе, который выглядит и ведёт себя как
установленное приложение, хотя технически не .apk. Папка `android/`
на это никак не влияет, можно просто игнорировать.

## Как проверить у себя на компьютере (не обязательно)

```
python -m http.server 8080
```
и открыть `http://localhost:8080` в браузере — удобно, чтобы один раз
глянуть, что всё работает, перед загрузкой на GitHub.

## Структура проекта

```
index.html, game.js, config.js   — сама игра (веб-версия)
manifest.webmanifest, sw.js       — для варианта "сайт как приложение" (необязательно)
icons/                             — иконки
assets/                            — твои картинки, музыка, звуки (уже на месте)
android/                           — обёртка для сборки .apk (не трогать руками)
.github/workflows/build-apk.yml    — настройка автосборки на GitHub
```

Настройки игры (вес выпадения, очки, физика, тексты) — в `config.js`,
это тот же конфиг, что в `config.json` компьютерной версии.
